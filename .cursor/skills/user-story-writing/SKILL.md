# User Story Writing Skill

## When to use
Use this skill whenever the user requests user stories or development-ready requirements.

## Instructions
1. Understand the feature context and user roles.
2. Identify the main user journeys.
3. Write user stories using: As a [role], I want [action], so that [benefit].
4. Include testable acceptance criteria.
5. Include edge cases and error handling.
6. Identify missing business rules.

## Output format
| User Story | Acceptance Criteria | Edge Cases / Error Cases |
|---|---|---|

## Rules
- Write clearly for developers, QA, and non-technical stakeholders.
- Do not invent confirmed requirements.
- Keep the output concise and testable.
